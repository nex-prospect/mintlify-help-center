A aba **Ferramentas** exibe as automações que o agente pode executar durante uma conversa, com base em gatilhos definidos por você.

**Para acessar:** Agentes → selecione um agente → aba Ferramentas

## O que são ferramentas?

Ferramentas são ações que o agente executa autonomamente quando detecta determinadas condições na conversa. Cada ferramenta é ativada por **gatilhos automáticos** que você configura em linguagem natural.

<Note>
  Para ativar ou desativar ferramentas globalmente na conta, acesse **Integrações → Ferramentas → Tools**.
</Note>

## Ferramentas disponíveis

| Ferramenta | Descrição |  |
| --- | --- | --- |
| **Atualização automática de status** | Troca o status do lead automaticamente quando um gatilho é detectado na conversa. |  |
| **Adição automática de tag** | Adiciona uma tag ao lead quando um gatilho é detectado. |  |
| **Remoção automática de tag** | Remove uma tag do lead quando um gatilho é detectado. |  |
| **Atualização automática de informações do lead** | Atualiza campos do lead (nome, e-mail, telefone, empresa, campos personalizados) quando um gatilho é detectado. |  |
| **Parar a IA** | Pausa o agente neste lead quando um gatilho é detectado. |  |

### Gatilhos automáticos _(obrigatório)_

Condições em linguagem natural que disparam a ferramenta automaticamente. Defina pelo menos um gatilho descrevendo o evento que deve acionar a ação.

**Exemplo:** _"cliente confirmou a compra"_ → a ferramenta muda o status do lead para "Fechado".

Clique em **\+ Adicionar gatilho** para incluir múltiplas condições.

### Exemplos _(opcional — melhora a precisão)_

Forneça casos de uso concretos para o agente entender melhor quando acionar a ferramenta. Cada exemplo mostra o que o lead diz e qual deve ser a ação resultante. Isso reduz ambiguidades e aumenta a precisão.

Clique em **\+ Adicionar exemplo** para incluir exemplos.
