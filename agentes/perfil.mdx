A aba **Perfil** define a identidade do agente: como ele é identificado no sistema, qual nome usa com os leads, sua personalidade e a mensagem de boas-vindas.

**Para acessar:** Agentes → selecione um agente → aba Perfil

## Como configurar o perfil do agente

### 1. Nome do Assistente no Sistema

Digite o nome identificador do agente dentro da plataforma Leavo. Esse nome é usado para organização interna e aparece na lista de agentes — o lead não o vê.

<img
  src="/images/image-33.png"
  alt="Image"
  title="Image"
  style={{ width:"98%" }}
/>

### 2. Nome do assistente

Digite o nome que o agente usará para se apresentar ao lead durante as conversas (ex.: "Ana", "Suporte Leavo").

![Image](/images/image-34.png "Image")

### 3. Personalidade

Escreva em texto livre como o agente deve se comportar: tom de voz, estilo de comunicação, técnicas de abordagem e qualquer diretriz comportamental. Quanto mais detalhado, mais consistente será o agente.

![Image](/images/image-35.png "Image")

### 4. Mensagem de boas-vindas

Digite a primeira mensagem que o agente enviará ao lead. Você pode usar variáveis dinâmicas para personalizar o texto:

| Variável | O que insere |  |
| --- | --- | --- |
| `{{LEAD_NAME}}` | Nome do lead |  |
| `{{LEAD_COMPANY}}` | Empresa do lead |  |
| `{{GREETING}}` | Saudação baseada no horário (Bom dia, Boa tarde, Boa noite) |  |

![Image](/images/image-36.png "Image")

### 5. Prestar suporte para

Digite o nome da empresa que o agente representa. Essa informação é usada internamente para que o agente saiba em nome de quem está atuando.

![Image](/images/image-37.png "Image")

### 6. Descreva um pouco sobre \[empresa\]

Escreva uma descrição breve da empresa — produto, serviço ou contexto de atuação. O agente usa esse texto para contextualizar as conversas com os leads.

![Image](/images/image-38.png "Image")

## Como ativar ou pausar o agente

Clique no toggle **Ativo** no canto superior direito para ativar ou pausar o agente. Um agente inativo não responde a novas conversas.

## Como salvar as alterações

- Clique em **Salvar Alterações** para confirmar manualmente.
