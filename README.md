# Central de Ajuda Leavo AI

Documentação da plataforma Leavo AI, construída com [Mintlify](https://mintlify.com).

## Desenvolvimento local

```bash
npm i -g mintlify
mintlify dev
```

## Estrutura

- `introduction.mdx` — Por onde começar (página inicial)
- `dashboard.mdx` — Dashboard
- `agendamentos.mdx` — Agendamentos
- `canais/` — Conectar WhatsApp, templates Meta, slots de canal
- `leads/` — Cadastro, importação, organização de leads
- `agentes/` — Criação e configuração dos agentes de IA
- `conversas/` — Lista, filtros e ferramentas da tela de conversa
- `cadencias/` — Sequências automatizadas de mensagens
- `pipeline/` — Funil de negócios em kanban
- `campanhas/` — Disparos em massa via API Oficial Meta
- `conhecimento/` — Base de conhecimento dos agentes
- `integracoes/` — Integrações externas (Google Agenda)

O conteúdo segue a estrutura definida pelo time de suporte em `leavo_help_center/`.
