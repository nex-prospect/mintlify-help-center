# Central de Ajuda Leavo AI

Documentação da plataforma Leavo AI, construída com [Mintlify](https://mintlify.com).

## Desenvolvimento local

```bash
npm i -g mintlify
mintlify dev
```

## Estrutura

- `introduction.mdx` — Página inicial / Bem-vindo
- `quickstart.mdx` — Dashboard
- `account-setup.mdx` — Conversas
- `concepts/` — Base de Conhecimento, Agentes de IA, Canais
- `guides/` — Cadências, Integrações, Leads, Pipeline
- `integrations/` — Agendamentos, Configurações, Ajuda e Suporte
