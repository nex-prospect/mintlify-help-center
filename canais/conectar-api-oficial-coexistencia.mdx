A conexão via **coexistência** permite que você use um número de WhatsApp Business já existente na Leavo sem abrir mão do aplicativo no seu celular. Enquanto a API Oficial está ativa, você continua recebendo e enviando mensagens normalmente pelo app — ideal para equipes que ainda querem manter o acesso manual ao mesmo número.

<Warning>
  Antes de iniciar a conexão via API Oficial, entre em contato com o suporte da Leavo para que a funcionalidade seja liberada na sua conta. Sem essa liberação prévia, o processo não será concluído.
</Warning>

## Pré-requisitos

Antes de começar, certifique-se de ter:

- **WhatsApp Business** instalado no celular com o número que deseja conectar (não funciona com o WhatsApp comum)
- Acesso a uma conta **Facebook** (pessoal ou empresarial) vinculada a um **Meta Business Manager**
- Número de telefone **ativo** e sem bloqueios na Meta

---

## Passo a passo

### 1. Acesse a seção Canais

No menu lateral da Leavo, clique em **Canais**. Localize o canal de WhatsApp que deseja conectar via API Oficial e clique em **Reconectar**.

<Note>
  Ao clicar em Reconectar, uma nova tela será aberta automaticamente. É nessa tela que você fará o login com o Facebook e autorizará a conexão.
</Note>

---

### 2. Faça login com o Facebook

Na tela que abrir, clique em **Continuar com o Facebook**. Você pode usar sua conta pessoal do Facebook ou a conta que utiliza para fins empresariais — o importante é que ela tenha acesso ao Meta Business Manager onde o número está (ou será) registrado.

Autorize os acessos solicitados e avance para a próxima etapa.

---

### 3. Selecione ou crie seu Meta Business Manager

Após o login, será solicitado que você selecione um **Meta Business Manager (BM)**. Escolha o BM ao qual o número pertence.

Caso ainda não tenha um BM configurado, a Meta oferecerá a opção de criar um novo durante este fluxo.

---

### 4. Escolha a opção de Coexistência

Nesta etapa, você verá duas opções de conexão. Escolha:

> **"Conectar seu app com o WhatsApp Business existente"**

Essa opção é a coexistência — ela mantém o número vinculado ao aplicativo do celular enquanto também conecta à API.

<Warning>
  Essa opção só estará disponível se o número já estiver ativo no aplicativo **WhatsApp Business**. Se você usa o WhatsApp comum (não Business), a coexistência não é suportada.
</Warning>

---

### 5. Leia o QR Code no celular

Após selecionar a coexistência, um **QR Code** será exibido na tela. Abra o **WhatsApp Business** no celular e leia o QR Code normalmente, assim como faz para conectar o WhatsApp Web.

<Note>
  O processo de leitura e autenticação pode levar entre **40 e 45 segundos**. Aguarde sem fechar a tela.
</Note>

---

### 6. Aguarde a confirmação

Assim que o QR Code for lido com sucesso, o status do canal na Leavo mudará automaticamente de **Aguardando** para **Conectado**. Você não precisa fazer mais nada — a conexão é estabelecida em segundo plano.

---

### 7. Confirme o status do canal

De volta à seção **Canais** na Leavo, verifique que o status do canal agora aparece como **Conectado**. A partir desse momento, as mensagens recebidas nesse número serão processadas pela API Oficial e distribuídas conforme as configurações da sua conta.

## Perguntas frequentes

<AccordionGroup>
  <Accordion title="Posso continuar usando o WhatsApp Business no celular após conectar?">
    Sim! A coexistência foi criada exatamente para isso. Você mantém o acesso ao app do celular e a API Oficial funciona em paralelo. As mensagens chegam nos dois lugares simultaneamente.
  </Accordion>

  <Accordion title="O que acontece se eu sair do WhatsApp Business no celular?">
    Se o número for desconectado do app (por exemplo, ao fazer login em outro aparelho), a coexistência pode ser interrompida. Nesse caso, será necessário reconectar via QR Code novamente.
  </Accordion>

  <Accordion title="Por que preciso falar com o suporte antes de conectar?">
    A API Oficial via coexistência requer uma liberação no backend da Leavo para garantir que sua conta está apta para esse tipo de conexão. Sem essa liberação, o fluxo não será concluído corretamente.
  </Accordion>

  <Accordion title="Qual o parceiro utilizado para a API Oficial?">
    A Leavo utiliza a **Gupshup** (parceiro: ODCEM Technologies Pvt. Ltd.) como intermediário para a conexão com a API Oficial do WhatsApp. Esse parceiro é homologado pela Meta para fornecer acesso à API.
  </Accordion>

  <Accordion title="E se o QR Code expirar antes de eu conseguir ler?">
    Se o QR Code expirar, basta fechar a tela e clicar em Reconectar novamente para gerar um novo QR Code. O processo recomeça do início.
  </Accordion>
</AccordionGroup>
